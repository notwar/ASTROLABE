Pick a colour from anywhere

How it works. This tool tells you which value to type in your app so a colour comes out exactly right in the final file. Use it when CGI work has to match a brand colour from the guidelines.

  1. In Output, pick the colour space of the final file (for example sRGB or Rec.709) and the colour it must have.
  2. In Input, pick the colour space your app works in (for example ACEScg).
  3. Input now shows the values to type into your app. If they can't land exactly on your colour, a note says so.

Changing values. Drag any number box left or right to change it (Shift 10× faster, Ctrl 10× finer), or click it to type. Both sides work: the side you changed last drives the other.

Warnings. Notes with a ! appear when a value falls outside its colour space (display values below 0 or above 1.0, linear values below 0) or would clip in the final file.

Built on OpenColorIO and ACES maths (OpenColorIO Project; A.M.P.A.S.). Licences are in the README next to the app.
